# Python Kvant

Курс по изучению языка Python.

В этом репозитории собраны учебные материалы: методички и презентации к занятиям. Здесь ты можешь скачать всё, что нужно для учёбы.

## Как пользоваться

Материалы разложены по разделам, а внутри разделов по темам. Открой нужную папку и скачай файл.
