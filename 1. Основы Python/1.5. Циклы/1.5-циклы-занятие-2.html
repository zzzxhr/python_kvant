Блок 1 · Вложенные циклы

Что такое вложенный цикл и зачем

Вложенный цикл — цикл внутри другого цикла. Как часы: за каждый час минутная стрелка проходит полный круг.

Без вложенного: ряд копируем вручную
С вложенным: 4 строки на любое число рядов
Внутренний цикл рисует один ряд, внешний повторяет ряды.
Блок 1 · Вложенные циклы

Как записывается вложенный цикл

внешний цикл: row = 0, 1, 2 — 3 круга
внутренний цикл: col = 0 … 4 — 5 кругов на каждом круге внешнего
итого тело внутреннего цикла выполнится 3 × 5 = 15 раз
Отступ решает, где команда: 8 пробелов — в каждом месте, 4 — один раз за ряд.

Пример: места в кинозале

Разбор

  • Строка 1 — внешний цикл: ряды 1, 2, 3.
  • Строка 2 — подпись ряда, один раз на ряд.
  • Строки 3–4 — внутренний цикл: места 1–4 в одну строку (end=" ").
  • Строка 5 — print(): ряд готов, переходим на новую строку.
За один круг внешнего цикла внутренний проходит целиком.

Внутренний цикл зависит от внешнего

В range внутреннего цикла можно подставить переменную внешнего — тогда ряды разной длины.

Разбор

  • row = 1 — range(1, 2): один #.
  • row = 4 — range(1, 5): четыре #.
  • Каждый следующий ряд на один символ длиннее.
Если внутренний range зависит от внешней переменной, получаются лесенки и треугольники.

Блок 2 · Случайные числа

Что такое случайное число и зачем

Случайное число — число, которое заранее неизвестно, как результат броска кубика.

Где нужно

  • кубик в настольной игре;
  • враг появляется в случайном месте;
  • компьютер загадывает число;
  • генератор паролей.

Без него

Программа при каждом запуске делает одно и то же: игру один раз прошёл — и всё уже знаешь.

Случайность делает так, что программа при каждом запуске ведёт себя по-новому.

Случайные числа живут в готовом наборе функций random. Его нужно подключить.

имя набора, точка, имя функции

Пока просто запомни эту запись

Подробно о том, что такое import и наборы функций (модули), — в теме 3.4.

import random — в начале файла, потом пишем random.имя_функции(...).

random.randint(a, b) — случайное целое число от a до b, оба конца входят.

randint(1, 6) даёт одно из чисел 1, 2, 3, 4, 5, 6 — каждый раз новое.

Блок 3 · else и while True

else у цикла: «если не было break»

else после цикла выполняется, если цикл дошёл до конца сам, без break.

Ищешь ключи по всем карманам: нашёл — стоп (break); проверил все и не нашёл — «ключей нет» (else).

Зачем

В ★★ «Сейф» прошлого занятия пришлось заводить переменную-флаг. С else она не нужна.

else у цикла выполняется, только если не сработал break.

else не на том отступе

else у if — внутри цикла
else у for — под for

Почему

С отступом 4 это else от if: «Цифр нет» печатается на каждой букве. else цикла пишется ровно под for.

Блок 3 · else и while True

while True: выход изнутри

while True — цикл без условия, выходим только через break. Удобно, когда проверка — в середине: сначала спросить, потом проверить.

.isdigit() — True, если в строке только цифры (тема 1.2).

while True повторяет, пока изнутри не сработает break.
! Ловушка Блок 3 · else и while True

while True без break: «выход» не работает

Забыли break
break после «Пока!»

Почему

Без break цикл while True никогда не закончится: «Пока!» напечаталось, а программа снова спрашивает. Остановить — Ctrl+C или «Стоп». У каждого while True должен быть break.

Проверь себя: else и while True

1. Что выведет программа A?

break не было — цикл закончился сам, сработал else.

2. Что выведет программа B, где range пустой?

Ни одного круга, но и break не было — else выполнился.

3. Зачем while True, если есть while с условием?

Когда решение «выходить или нет» удобно принять в середине тела: после input. Выход — через break.

Вопросы по всей теме «Циклы»

1. Чем random.randint(1, 10) отличается от range(1, 10)?

randint даёт одно случайное число от 1 до 10 включительно. range — все числа по порядку от 1 до 9.

2. Что будет, если в «Угадай число» перенести randint внутрь while?

Число будет загадываться заново на каждой попытке — подсказки потеряют смысл, выиграть можно только случайно.

3. Когда писать while True, а когда while с условием (занятие 1)?

Условие известно заранее («пока накоплено меньше цели») — while с условием. Решаем в середине тела, после ввода, — while True и break.
