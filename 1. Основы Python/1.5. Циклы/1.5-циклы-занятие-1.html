Блок 1 · Цикл while

Что такое цикл и зачем он нужен

Цикл — повторение одних и тех же команд. Как на стадионе: «пока не пробежал 5 кругов — беги ещё круг».

Без цикла: строка на каждый круг
С циклом: 4 строки на любое число кругов
Цикл повторяет команды за нас: для 100 кругов меняем одно число, а не пишем 100 строк.
Блок 1 · Цикл while

Как записывается while

while

«пока»: повторяй, пока условие верно

условие:

как в if (тема 1.4): True — ещё круг, False — выход из цикла

тело цикла

команды с отступом 4 пробела — они и повторяются

while проверяет условие перед каждым кругом и повторяет тело, пока условие True.
Блок 1 · Цикл while

Пример: обратный отсчёт

Разбор

  • Строка 1 — count = 5: с этого числа начинаем.
  • Строка 2 — перед каждым кругом проверяем count > 0.
  • Строки 3–4 — тело: печатаем и уменьшаем на 1.
  • Когда count стал 0, условие False — выполняется строка 5.
Внутри цикла что-то должно меняться, чтобы условие однажды стало False.

По шагам: обратный отсчёт

Жми «Шаг →» и следи за count и выделенной строкой.

Условие проверяется 4 раза, а тело выполняется 3 раза: последняя проверка выводит из цикла.
Блок 1 · Цикл while

Счётчик: сколько было попыток

Счётчик — переменная, которая считает, сколько раз что-то случилось.

  • tries = 1 — первую попытку делаем ещё до цикла.
  • tries += 1 — каждая новая попытка.
  • != — «не равно»: повторяем, пока пароль неверный.
Счётчик: начальное значение до цикла, внутри цикла — tries += 1.
Блок 1 · Цикл while

Накопитель: копим сумму

Накопитель — переменная, в которую на каждом круге добавляем значение. Как копилка.

Разбор

  • total = 0 — до цикла: копилка пустая.
  • total += steps — добавили шаги этого дня.
  • day — счётчик дней: цикл идёт 3 круга.
Счётчик прибавляет 1, накопитель — само значение. Оба создаются до цикла.

Почему

count всегда 5, условие count > 0 всегда True. Как правильно: в теле меняй count — count -= 1.

Накопитель обнуляется на каждом круге

total = 0 внутри цикла

Почему

Строка 3 каждый круг опустошает копилку, и остаются шаги только последнего дня. Начальное значение — до цикла.

Блок 2 · Цикл for и range

Что такое for и зачем он нужен

for — цикл «для каждого»: переменная по очереди получает каждое значение из набора. Как учитель, который идёт по журналу по порядку.

while: счётчик ведём сами
for: счётчик меняется сам

range(1, 6) — числа 1, 2, 3, 4, 5. Подробно — через слайд.

Когда известно, сколько раз повторять, for короче и не даёт забыть увеличить счётчик.
Блок 2 · Цикл for и range

Как записывается for

for имя

переменная цикла: на каждом круге в ней новое значение

in range(...):

откуда брать значения: range даёт числа по порядку

тело цикла

команды с отступом — выполняются для каждого значения

for сам перебирает значения: увеличивать счётчик вручную не нужно.
Блок 2 · Цикл for и range

Три формы range

range(start, stop, step) — числа от start до stop с шагом step. stop не входит.

Одно число — это stop. Начало 0, шаг 1: ровно 5 кругов.

start = 1, stop = 6. Само 6 не входит.

step = 5: каждое следующее на 5 больше. 20 не входит.

Отрицательный шаг — счёт назад. Тогда start больше stop.

print(i, end=" ") — печать в одну строку через пробел (тема 1.2).

range(start, stop, step): start входит, stop — никогда.

Блок 3 · break и continue


break: выйти из цикла раньше


break — сразу выйти из цикла. Как с ключами: нашёл в первом кармане — остальные не проверяешь.










Зачем и как работает
    

  • Цифра уже найдена — искать дальше незачем.
    • 

  • Строка 5 — break: цикл закончился, строка 6 не выполнилась.
    • 

  • До символа "9" цикл так и не дошёл.
    • 





break сразу заканчивает цикл: оставшиеся строки тела и круги не выполняются.






Блок 3 · break и continue


continue: пропустить шаг


continue — пропустить остаток тела и перейти к следующему кругу. Как пустую страницу в тетради: пролистываешь и смотришь дальше.










Зачем и как работает
    

  • Убираем лишнее, не останавливая цикл.
    • 

  • Символ "_" — continue, и print для него не выполняется.
    • 

  • end="" — печать подряд, без пробела (тема 1.2).
    • 





continue пропускает только текущий круг, цикл идёт дальше. break выходит из цикла совсем.

Вопросы по занятию




1. Чем while отличается от if с тем же условием (тема 1.4)?
if проверяет условие один раз и выполняет тело не больше одного раза. while повторяет тело, пока условие True.


2. В «Кассовом чеке» ты выходил из цикла по нулю через break. Что будет, если вместо break написать continue?
Ноль больше не останавливает: программа всегда спросит все 5 цен, а ноль просто пропустится.


3. Какой цикл выбрать: а) задать 10 примеров; б) переспрашивать, пока ответ неверный?
а) for с range(1, 11) — число повторов известно. б) while — сколько будет попыток, заранее неизвестно. Так устроен мини-проект.








★ Мини-проект 15 минут вместе с итогами


Мини-проект: «Тренажёр таблицы умножения»






Программа тренирует одно число таблицы умножения: задаёт 10 примеров по порядку, переспрашивает, пока не ответишь верно, и считает ошибки.
Слово «стоп» — закончить раньше и посмотреть итог.
Это та программа, которую ты видел в начале занятия.

Номер автобуса — число от 1000 до 9999. Он счастливый, если сумма первых двух цифр равна сумме двух последних: 2341 → 2 + 3 = 4 + 1.


Посчитай, сколько всего счастливых номеров. Цифры достаёшь через // и % (тема 1.3).
